# Docs, the Rajo wiki

A navigable wiki authored as the product is built, one theme per folder with a same-named landing page and
numbered deep pages inside. The offline bake, its validation and these pages are the primary product; the
web app is a projection of the validated artifacts plus the browser-side lanes.

| Folder | What |
|---|---|
| [architecture/](architecture/architecture.md) | how the repository works: the lanes (bake, replay, live), the two data contracts, determinism, the deploy |
| [data/](data/data.md) | every source, probed and licensed; the attribution block; the site catalog contract |
| [methods/](methods/methods.md) | the twelve methods, one page each: theory, equations, sources, caveats, what runs where |
| [sites/](sites/sites.md) | the catalog: categories, coverage, one page per site with sourced facts |
| [guides/](guides/guides.md) | run the bake, bring your own site, train the models, deploy |

Honesty policy: numbers come from computations or committed artifacts, never from a claim; every external
figure carries a source and a date; anything unverified is labelled so.
